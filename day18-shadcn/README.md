# SaaS Dashboard

**Live:** https://saas-dashboard-woad-pi.vercel.app

**Stack:** Next.js (App Router), Tailwind v4, shadcn/ui, Recharts

## Features
- Dashboard layout with sidebar navigation and header
- Stat cards and a weekly chart built with Recharts
- Users table and a posts list fed by mock data and a public API
- Contact dialog built with shadcn/ui components

## Run locally
npm install
npm run dev
